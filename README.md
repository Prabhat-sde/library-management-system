# 📚 Library Management System

A web-based **Library Management System** developed using **Python Flask, SQLite, and SQLAlchemy**. The project helps manage books, students, users, and book issue/return records through a simple web interface.

## ✨ Features

- 👤 User Registration & Login
- 🔐 Secure Password Hashing
- 👨‍💼 Admin & User Roles
- 📚 Add, Edit, Delete & Search Books
- 🎓 Student Management
- 📕 Issue Books
- 📗 Return Books
- 📊 User & Admin Dashboard
- 🔎 Book Search & Category Filtering
- 👤 User Profile
- 📖 My Books & Student History

## 🛠️ Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- SQLAlchemy
- HTML5
- CSS3
